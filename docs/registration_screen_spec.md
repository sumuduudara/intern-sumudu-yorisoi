# ユーザー登録画面の仕様

## 1. 概要

新規ユーザーがYorisoiのアカウントを作成するための画面です。

メールアドレスとパスワードを入力して登録します。

登録が成功した場合は、ホーム画面に遷移します。

## 2. 入力項目

ユーザー登録画面には、以下の入力項目を表示します。

### メールアドレス

- 必須項目です。
- メールアドレスを入力します。

### パスワード

- 必須項目です。
- 入力した文字は非表示にします。

### パスワード確認

- 必須項目です。
- パスワードをもう一度入力します。

## 3. 入力チェック・エラー表示

登録ボタンを押したときに、入力内容を確認します。

### 1. 未入力の場合

メールアドレス、パスワード、パスワード確認の
いずれかが空欄の場合、
「必須項目を入力してください」と表示します。

### 2. メールアドレスの形式が正しくない場合

「正しいメールアドレスを入力してください」と表示します。

### 3. パスワードが短すぎる場合

「パスワードが短すぎます」と表示します。

### 4. パスワードが一致しない場合

パスワードと確認用パスワードが異なる場合、
「パスワードが一致しません」と表示します。

### 5. エラー表示方法

エラーメッセージは該当する入力欄の下に表示します。

入力エラーがある場合は、Firebase Authenticationに
登録リクエストを送信しません。

## 4. Firebase Authenticationによるユーザー登録

入力内容に問題がない場合、
Firebase Authenticationを使用してユーザーを登録します。

### 1. 登録処理中

- 登録ボタンを押すと、登録処理を開始します。
- 処理中はローディング表示を行います。
- 二重送信を防ぐため、登録ボタンを無効にします。

### 2. 登録成功

- 登録が成功した場合、ホーム画面に遷移します。

### 3. 登録失敗

- 登録に失敗した場合、エラーメッセージを表示します。
- メールアドレスが既に登録されている場合は、
  「このメールアドレスは既に登録されています」と表示します。
- 通信エラーが発生した場合は、
  「通信エラーが発生しました。もう一度お試しください」と表示します。
- 登録に失敗した場合は、登録画面に留まります。

## 5. ログイン画面へのリンク

登録画面の下部に、ログイン画面へのリンクを表示します。

表示テキスト：
「すでにアカウントをお持ちの方はこちら」

リンクをタップすると、ログイン画面に遷移します。

ログイン画面から登録画面に戻ることもできます。

- [ ] 未入力の場合のエラーが定義されている。
- [ ] メールアドレスの形式チェックが定義されている。
- [ ] パスワードの長さチェックが定義されている。
- [ ] パスワード不一致のエラーが定義されている。
- [ ] Firebase Authenticationによる登録処理が定義されている。
- [ ] 登録中のローディング表示が定義されている。
- [ ] 登録成功後のホーム画面への遷移が定義されている。

## 7. 確認事項

パスワードの最小文字数は未確定のため、
実装前に確認する必要があります。
