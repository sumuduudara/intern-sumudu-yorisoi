# ユーザー登録画面の仕様

## 1. 概要

新規ユーザーがYorisoiのアカウントを作成するための画面です。

メールアドレスとパスワードを入力して登録します。

登録が成功した場合は、ホーム画面に遷移します。

## 2. 入力項目

ユーザー登録画面には、以下の入力項目を表示します。

### ニックネーム（任意）

- Figmaの入力欄に合わせて追加。空欄でも登録できる。
- 入力した場合は登録成功後にFirebase AuthenticationのdisplayNameへ保存する。
- profile保存だけが失敗した場合、アカウント作成を再実行せず、保存失敗を案内してHomeへ進む。

### メールアドレス

- 必須項目です。
- メールアドレスを入力します。

### パスワード

- 必須項目です。
- 入力した文字は非表示にします。

### パスワード確認

- 必須項目です。
- パスワードをもう一度入力します。

## 3. 入力チェック・エラー表示

登録ボタンを押したときに、入力内容を確認します。

### 1. 未入力の場合

メールアドレス、パスワード、パスワード確認の
いずれかが空欄の場合、
該当欄ごとに「メールアドレスを入力してください」、
「パスワードを入力してください」、「パスワード確認を入力してください」と表示します。

### 2. メールアドレスの形式が正しくない場合

「正しいメールアドレスを入力してください」と表示します。

### 3. パスワードが短すぎる場合

6文字未満の場合「パスワードは6文字以上で入力してください」と表示します。

### 4. パスワードが一致しない場合

パスワードと確認用パスワードが異なる場合、
「パスワードが一致しません」と表示します。

### 5. エラー表示方法

エラーメッセージは該当する入力欄の下に表示します。

入力エラーがある場合は、Firebase Authenticationに
登録リクエストを送信しません。

## 4. Firebase Authenticationによるユーザー登録

入力内容に問題がない場合、
Firebase Authenticationを使用してユーザーを登録します。

### 1. 登録処理中

- 登録ボタンを押すと、登録処理を開始します。
- 処理中はローディング表示を行います。
- 二重送信を防ぐため、登録ボタンを無効にします。

### 2. 登録成功

- 登録が成功した場合、ホーム画面に遷移します。

### 3. 登録失敗

- 登録に失敗した場合、エラーメッセージを表示します。
- メールアドレスが既に登録されている場合は、
  「このメールアドレスは既に登録されています」と表示します。
- 通信エラーが発生した場合は、
  「通信エラーが発生しました。もう一度お試しください」と表示します。
- 登録に失敗した場合は、登録画面に留まります。

## 5. ログイン画面へのリンク

登録画面の下部に、ログイン画面へのリンクを表示します。

表示テキスト：
「アカウントをお持ちの方 · Have an account? ログイン」

リンクをタップすると、ログイン画面に遷移します。

ログイン画面から登録画面に戻ることもできます。

## 7. 確認事項

現在の登録実装は6文字以上。Figmaの「8文字以上」というhintだけを根拠に、
既存の登録条件を変更しない。画面のhintも6文字以上と表示する。
パスワード再設定の新規フォームには別途Figmaの8文字以上・英字と数字の条件を適用する。

2026-10-29のauth UI統合と検証範囲は [auth_ui_integration.md](auth_ui_integration.md) を参照。
